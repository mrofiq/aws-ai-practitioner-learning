# AWS AI Practitioner Learning

Learn to pass AWS AI Practitioner (AIF-C01) Exam

## 🚀 Features

- **SvelteKit** - Latest version with TypeScript support
- **Tailwind CSS** - With typography and forms plugins
- **Vercel Deployment** - Optimized adapter for Vercel hosting
- **Vitest** - Unit and component testing
- **ESLint & Prettier** - Code linting and formatting
- **GitHub Copilot** - Agentic AI coding support

## 📋 Prerequisites

- Node.js 20+
- npm

## 🛠️ Getting Started

### Install dependencies

```bash
npm install
```

### Development

```bash
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

### Build

```bash
npm run build
```

### Run tests

```bash
npm run test
```

### Linting

```bash
npm run lint
```

### Format code

```bash
npm run format
```

### Type checking

```bash
npm run check
```

## 🤖 Agentic AI Coding with GitHub Copilot

This project is set up for agentic AI coding with GitHub Copilot:

1. Install the recommended VS Code extensions
2. Sign in to GitHub Copilot
3. Use Copilot Chat for code assistance
4. Leverage inline suggestions while coding

## 🚢 Deployment

This project is configured for Vercel deployment:

1. Connect your repository to Vercel
2. Vercel will automatically detect SvelteKit
3. Each push to `main` triggers deployment
